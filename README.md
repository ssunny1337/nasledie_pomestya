# Наследие поместья — PWA

## Что внутри
- `index.html` — интерфейс и логика квеста.
- `manifest.webmanifest` — настройки установки на домашний экран.
- `sw.js` — кэширование для офлайн-работы после первого открытия.
- `icon.svg` — иконка.

## Как открыть на iPhone
PWA нужно разместить на HTTPS-хостинге (например, GitHub Pages или Netlify).
После публикации:
1. Откройте ссылку в Safari на iPhone.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой» / Add to Home Screen.
4. Запустите приложение с появившейся иконки.

После первого открытия приложение кэшируется и может работать без интернета.
Прогресс сохраняется в локальном хранилище браузера на этом устройстве.

## Важно перед квестом
- Проверьте, что подарки действительно лежат в указанных местах.
- Вторая загадка ведёт на верхний ярус/полку шкафа — при необходимости поменяйте текст в `index.html`.
- Кнопка «Начать квест заново» сбрасывает прогресс; не нажимайте её во время прохождения.

## Редактирование
Все тексты трёх этапов находятся в массиве `stages` внизу `index.html`.
